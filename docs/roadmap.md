- [x] Debian 13 live-build foundation
- [x] KDE Plasma package profile
- [x] Nivora wallpaper and desktop entry

- Hardware and OS information tools
- File search with scoped directories

- Permission UI

## 0.3 - Propose

- Package installation proposals
- Settings-change previews
- File-operation plans
- Human-readable diffs before execution

## 0.4 - Act

- Permission-gated actions
- Auditable tool history
- Rollback support where possible
- Fine-grained privilege broker

## 0.5 - Providers

- Optional cloud AI adapters
- Optional local model adapter
- Runtime credential storage
- Provider-independent Nivora tool protocol

## 1.0 - Daily driver experiment

The test: can an AI-native desktop be genuinely useful without making the computer less understandable or less controllable?
